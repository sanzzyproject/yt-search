🚀 Tentang Project

Aplikasi web Lyrics Music ini dikembangkan secara khusus untuk memberikan pengalaman UI/UX moderen layaknya aplikasi native Spotify, dilengkapi dengan sistem penyimpanan offline realtime dan kemampuan PWA (Progressive Web App).

🛠️ Tech Stack & Framework

  • Frontend UI: HTML5, CSS3 Modern
  • Frontend Logic: Vanilla JavaScript
  • Backend Framework: FastAPI (Python)
  • Library API Core: ytmusicapi
  • Database: IndexedDB (Offline Native Storage)
  • Deployment Server: Vercel Serverless Functions
